# World Anvil Handoff

World Anvil cannot be reached from Claude Code. There is no connector, none exists in the
registry, and worldanvil.com is blocked at the network layer of the execution container.
The working route is **Claude for Chrome**, on a tab already signed in.

**How to use this file.** Open the World Anvil tab. Open Claude for Chrome on it. Copy
everything between the two rules below and paste it as your first message. It is written to be
self-contained, because Claude for Chrome has none of this project's context and cannot read
this repository.

It runs in two phases on purpose. Phase one only looks and reports. Nothing is edited until
you have seen the audit and said go. Blind find-and-replace across a wiki is how canon gets
damaged quietly.

article that lacks it:

The guy-wire metaphor, wherever it is described:

  Psychagogue (SY-kuh-gog), from the Greek psyche, soul, and agogos, one who leads.
